# 书析 · 纯前端版

**不需要任何服务器，不需要 Minis 在后台运行。** 打开网页就能用。

## 怎么用

在 iPad 的 Safari 里打开这个地址：

```
http://192.168.1.3:8787/standalone/index.html
```

第一次打开会让你填 DeepSeek API Key（`sk-` 开头那种），填一次就记住了。

> 如果地址打不开，说明这台机器的 IP 变了。在 Minis 里执行
> `cd /var/minis/shared/booklab && ./run.sh status` 看当前地址。
> 或者直接把 `standalone/` 目录拷贝到任何静态网页托管上也能跑。

## 和工作原理

所有计算都在你的浏览器里：

- 导入的 txt / epub 用浏览器 API 解析
- 章节切分用 JavaScript 完成
- 拆书请求**直接从浏览器发到 DeepSeek**，不经过任何中间服务器
- 数据存在浏览器的 IndexedDB 里

所以 Minis 关掉、后台被杀，这个页面照样能用（只要之前加载过）。

## 和原来的后端版有什么区别

| | 纯前端版 | 后端版 |
|---|---|---|
| 需要 Minis 后台 | ❌ 不需要 | ✅ 需要 |
| 数据存哪 | 浏览器 IndexedDB | SQLite 文件 |
| txt / epub 导入 | ✅ | ✅ |
| 拆书 | ✅ | ✅ |
| 断点续拆 | ✅ | ✅ |
| 换设备/清缓存 | ❌ 数据丢失 | ✅ 不受影响 |
| 番茄小说抓取 | ❌ 已移除 | ✅ 有（仅片段） |
| API Key 位置 | 浏览器本地 | 服务器环境变量 |

## 三个要接受的限制

**① 数据只在这个浏览器里**
清除网站数据、换浏览器、换设备，书就没了。
重要的话建议导出——目前没做导出功能，可以自己从 IndexedDB 里取。

**② API Key 存在浏览器里**
同设备上打开这个页面的人能看到（虽然输入框是密码样式）。
这台 iPad 只有你用的话问题不大。

**③ 番茄抓取没有了**
浏览器有跨域限制，没法直接请求 fanqienovel.com。
另外字体解码要在内存里做几千次向量比对，浏览器扛不住。

## 文件

```
standalone/
├── index.html    界面 + 样式（单文件）
└── app.js        全部逻辑：解析、切分、拆书引擎、存储
```

没有构建步骤，没有依赖（epub 解析用 CDN 上的 JSZip）。
想改的话直接编辑这两个文件。
